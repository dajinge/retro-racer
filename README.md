# 怀旧赛车 (Retro Racer)

复刻 2008 年怀旧休闲赛车风格，2D 俯视角，纯 HTML5 Canvas 赛车游戏。

## 特性

- 🏎️ 2D 俯视角，固定地图全屏显示
- 🎮 双套操控：WASD / 方向键
- 🚗 加速惯性 + 柔和漂移
- 🗺️ 3 张赛道：新手村 → 标准赛道 → 进阶挑战
- 🧱 赛道边界碰撞与回弹
- 📦 零依赖，单文件，浏览器打开即玩

## 操控

| 按键 | 动作 |
|------|------|
| W / ↑ | 前进加速 |
| S / ↓ | 后退 |
| A / ← | 左转漂移 |
| D / → | 右转漂移 |

按住方向键过弯自动触发漂移，松键自动回正。

## 快速开始

```bash
# 直接用浏览器打开
open index.html

# 或启动本地服务器
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 赛道

| 地图 | 难度 | 特点 |
|------|------|------|
| 新手村 | 简单 | 椭圆环形，宽赛道，长直道 + 平缓大弯 |
| 标准赛道 | 中等 | 不规则环形，多弯道 + 浅 U 弯 |
| 进阶挑战 | 困难 | 紧凑环形，连续 S 弯 + 发卡弯 |

## 技术

HTML5 Canvas + 原生 JavaScript，无外部依赖。
