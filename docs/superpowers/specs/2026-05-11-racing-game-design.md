# 2D 俯视角怀旧赛车游戏 — 设计方案

**日期**: 2026-05-11
**状态**: 已确认

## 概述

复刻 2008 年怀旧休闲赛车风格，2D 俯视角，固定地图全屏显示，只有赛车在赛道上移动。纯几何图形 + 纯色块渲染，单 HTML 文件。

## 技术选型

- **HTML5 Canvas + 原生 JavaScript**，单个 `.html` 文件，CSS/JS 内嵌
- 游戏循环：`requestAnimationFrame`
- 无外部依赖，无需图片资源

## 数据结构

```js
gameState = {
  car: { x, y, angle, speed, driftOffset },
  track: { waypoints, width, bounds },
  input: { forward, backward, left, right }  // boolean
}
```

## 操控

| 按键 | 动作 |
|------|------|
| W / ↑ | 前进加速 |
| S / ↓ | 后退减速 |
| A / ← | 左转 / 漂移 |
| D / → | 右转 / 漂移 |

- `keydown`/`keyup` 事件设置 input 标志位
- `keydown` 时 `preventDefault()` 防止方向键滚动页面
- WASD 和方向键完全等效，可混用

## 物理模型

### 加速
- 按住前进键：`speed += acceleration * dt`，有 `maxSpeed` 上限
- 按住后退键：`speed -= reverseAcceleration * dt`，有 `maxReverseSpeed` 上限
- 松手惯性：`speed *= friction`（如 0.98/帧），缓慢自然减速

### 转向
- 正常行驶：`angle += turnRate * (speed / maxSpeed)`，速度越快转向越灵敏
- 速度为零时不转向

### 漂移
- 左/右键按下时自动进入漂移状态
- 产生侧向偏移 `driftOffset`，叠加到赛车横向位移
- 漂移幅度偏小、力度柔和，不会失控
- 漂移时有轻微速度损失
- 松开方向键 → `driftOffset` 快速衰减回零，车身回正

### 边界碰撞
- 赛道边界 = 路点中心线 ± 赛道宽度/2
- 赛车超出边界 → 投影回最近边界点 + 速度反向衰减（轻微回弹）

## 渲染层级

从底到顶：
1. 草地背景
2. 赛道沥青路面
3. 赛道边线/路肩
4. 赛车（矩形 + 三角朝向指示）

## 3 张地图

### 地图1 — 新手村
- 画布约 800×600
- 椭圆形环形赛道：两条长直道 + 两端 180° 平缓大弯
- 赛道宽，容错大

### 地图2 — 标准赛道
- 画布约 900×700
- 不规则环形：长直道 → 连续 90° 弯 → 短直道 → 浅 U 弯 → 回直道
- 赛道宽度适中

### 地图3 — 进阶图
- 画布约 900×600
- 紧凑环形：短直道穿插连续 S 弯 + 两个小急弯（发卡弯）
- 赛道相对窄

## 赛道定义方式

每条赛道用路点数组定义中心线：
- 路点之间直线段连接
- 赛道边界 = 中心线两侧各偏移 `trackWidth / 2`
- 碰撞检测：计算赛车到最近中心线段的垂直距离，与半宽比较

## 页面布局

- 顶部栏：地图选择按钮 + 当前地图名
- 主区域：Canvas 画布
- 底部/角落：操作提示（WASD / 方向键）

## 不在范围内

- 无计时/计分（纯休闲驾驶）
- 无音效/音乐
- 无 AI 对手
- 无道具/加速带
- 无地图编辑器
- 无存档/设置
